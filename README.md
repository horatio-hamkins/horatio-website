# horatio-hamkins.github.io

Personal website with two sections: **Research** (publications) and **Projects**.

Built on a fork of **Jekyll Now** ([barryclark/jekyll-now](https://github.com/barryclark/jekyll-now)), with a design modified from [Jon Barron's website](https://jonbarron.info/) (via [Leonid Keselman's site](https://leonidk.com)).

All content is static in `_layouts/default.html` — no posts, no PDFs, no images. To edit a section, edit the HTML tables directly.

## Building locally

```bash
bundle exec jekyll serve
```

## Deployment

Hosted on GitHub Pages as the user site `horatio-hamkins.github.io`.
